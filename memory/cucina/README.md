# Cucina Memory

Readable summaries and views of cooking sessions, sourdough maintenance, recipes, meal plans, and dietary preferences from the Cucina application.

- **Content**: Monthly cooking and baking summaries, sourdough feeding logs, recipe notes, and meal plan records.
- **Source**: Raw data stays in the Cucina application (`/home/beedme/data/workspace/cucina/data/`); only Markdown summaries and views are stored here.
- **Written by**: A periodic generator or chef agent on request (planned).
