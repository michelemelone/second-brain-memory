## Request

Context: the new Gantry requirement screen (RequirementWorkspace, see MIC-223, MIC-224, MIC-225, MIC-226, MIC-227, MIC-228, MIC-229) is messy. The owner attached a screenshot of PBI #167. The centre column currently holds the tabs PBI, Live and Open Questions, the type/title/follow-up header, the 'Validate with AI' chat and its buttons. The chat itself is broken: it has nested scrollbars and a squeezed, vertical 'Changes are only applied when you click Apply' text.

Goal: the centre column contains ONLY the conversation with the AI used to build and discuss the requirement (the Validate with AI chat, its input, and the actions that belong to that conversation: Validate with AI, Start delivery, Add change, Add bug). Everything else about the PBI moves to the left or right column, or into their tabs. This covers the type badges (Requirement/Bug/API Task), the #id, the title, the follow-up link, and the Live and Open Questions content, plus any other tab or PBI data.

Steps:
1. First propose a short layout in the task comment: what goes in the left column (title, type, description, acceptance criteria, attachments) and what goes in the right column (the Classification, Planning, Assignment and Dependencies tabs, plus Live status and Open Questions, perhaps as extra right-hand tabs). Choose the best arrangement yourself so both side columns are filled well, with no big empty areas, and then implement it.
2. Fix the chat so it fills the full height of the centre column with one single scroll area. The input sits at the bottom, with no nested scrollbars and no vertical word wrapping. The title must not be truncated in its new place.
3. Keep the mobile layout (3 tabs: left, chat, right) working with the same content split.
4. Work in the Gantry repo (gantry/programs). Deploy to dev only. Gantry Enterprise is not involved.

Check: test on desktop and mobile with screenshots. The centre shows only the AI chat. Every previous piece of PBI data is still reachable. Nothing is lost. Build and deploy before reporting done.

# Report: Task MIC-236

## Summary
Task **MIC-236** (Gantry: reorganise the requirement screen so the centre column is only the AI chat) has been completed, tested, and delivered.

The `RequirementWorkspace` layout has been restructured so that the centre column is dedicated exclusively to the AI conversation (Validation/Creation chat) and conversation-level actions.
