# MIC-459: Gantry PBI chat: answer box you can resize with Send and Edit, better point buttons, icons for Validate, Validate again and chat history

- Project: Gantry
- Status: done
- Priority: high
- Agent: Pegasus

- Updated: 2026-11-25

## Request

ACCEPTANCE CRITERIA
1. In the Validation points of the PBI chat (ValidationChatPanel.tsx, PointRow), the answer field opens as a textarea the user can enlarge and shrink vertically to write more text; Enter inserts a new line and Ctrl/Cmd+Enter sends (frontend test + screenshot).
2. The Send button sits next to the textarea and is disabled while it is empty. Pressing it shows a clear 'Saving your answer…' state, then the point shows the answer as saved ('Answered' with the text) (test + screenshot).
3. A saved answer has an Edit button: it reopens the textarea with the saved text and Send replaces the answer (test + screenshot).
4. A short hint under the textarea says the answer is saved only when Send is pressed; text typed and not sent is not lost silently: pressing Update requirement with unsent text asks to send it first (test).
5. Update requirement with unresolved points asks for confirmation ('N points are not resolved: update anyway?') and never silently drops them (test).
6. After Update requirement a clear confirmation tells that the PBI is updated and that Start run must be pressed to apply it (test; the text may reuse the existing one).
7. The Apply, Decline and Answer buttons and the footer buttons (Update requirement, Accept as is, Discard) are redesigned to look better and consistent with the Gantry design system (same tokens as the rest of the app, dark and light mode, keyboard focus visible) (screenshots in both themes).
8. The 'Validate' button of the chat's first message gets a fitting icon next to its label (e.g. a check/shield icon from the icon set already used by Gantry) (screenshot).
9. The 'Validate again' button in the chat header gets a fitting icon (e.g. a refresh/repeat icon), keeping an accessible name and a tooltip (screenshot + test of aria-label).
10. The text link 'Saved in your chats' is replaced by a history icon button with the tooltip 'Saved in your chats' and the same aria-label; it still opens /ask-ai?chat=<id> in a new tab (test + screenshot).
11. All UI strings in English; no Italian in the diff (grep). Existing tests of ValidationChatPanel are updated and pass.
12. Frontend built and deployed from a clean checkout of the latest commit, checked on the live Gantry (say the commit built).

Context: the owner could not tell how to confirm an answer in the chat of an existing PBI (Answer opens a one-line input and only Send or Enter saves it). Related: MIC-446 (validation points), MIC-437 (validation rounds). Verify live with bigmike-gantry for the API and screenshots of the real page.
