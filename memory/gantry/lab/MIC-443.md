## Request

1. Clicking 'New Requirement', 'New Bug', or 'New API Task' anywhere in Gantry navigates directly to the full requirement detail page instead of opening a popup modal. Verified by clicking each creation trigger in the web UI and checking that no modal dialog or overlay appears.
2. The requirement page opens in a clean, blank state ready for input (empty title, type set appropriately, blank description and fields). Verified by checking that form inputs are empty and editable on screen.
3. The obsolete creation modal dialog and its open/close state logic are removed from the frontend. Verified by inspecting React components in servicenow_ai/gantry/frontend and running frontend tests.
4. Creating/saving a requirement from the dedicated page persists the requirement correctly to the backend and reflects it in the Backlog. Verified by creating a requirement, a bug, and an API task, checking state.json and PBI.md creation, and confirming they appear in the Backlog list.

Remove the modal popup used when adding a new requirement, bug, or API task in Gantry. Replace the popup trigger with direct navigation to the requirement page initialized in create/empty mode. Keep existing validation rules and PBI persistence logic intact.
