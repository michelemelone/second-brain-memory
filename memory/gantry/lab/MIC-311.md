### What Was Done

1. **Repack Algorithm in `panelFit.ts` (`computeFit`)**:
   - Enhanced `computeFit` to support optional `contentWidth`.
   - When `contentWidth` is specified on panels, each panel is allocated its content width bounded by `[min, max]`.
   - Any leftover space (`available - totalBase`) is distributed proportionally by `weight` among expanding panels. Panels with `weight: 0` remain strictly at their compact content width without bloating.
   - If available space is constrained, panels scale down proportionally to their minimum limits.

2. **Documents Tab & Markdown Viewer (`DocumentationExplorer.tsx` & `DocViewer.tsx`)**:
   - Set `EXPLORER_MIN` to 260 px (from 220 px) so the Explorer toolbar buttons ("Explorer", "Expand", "Collapse", "Refresh") and file names never truncate or cut off.
   - In `DocumentationExplorer`, auto-fit sets the tree to its content width (260 px) and awards the remaining space to the Markdown viewer.
   - In `DocViewer`, editor base content width is 560 px while preview takes the majority of leftover space instead of splitting 50/50.

3. **Requirement Workspace (`RequirementWorkspace.tsx`)**:
   - Auto-fit sets the left description form to a compact base (300 px), respects the 1/3 cap for the Validate with AI chat (at most 33% of the total form width), and awards the remaining space to the right panel (PBI/Documents tabs) so that Explorer + Viewer can fit side by side when room allows.

4. **Table Column Auto-Fit in `LabTable.tsx` & `LabToolbar.tsx`**:
   - Implemented `computeTableColumnWidths()`: measures and compacts non-flexible columns (`id`, `type`, `state`, `iteration`, `priority`, `cost`, `actions`) to their content width.
   - Designates `title` (or primary text column) as the flexible column absorbing all remaining table width.
   - Applied `table-fixed` when widths are active, preventing the browser from stretching compact columns with large blank gaps.
   - Registered `LabTable` with `registerFitLayout` so the header "Auto-fit columns" button triggers table auto-fit.
   - Added an "Auto-fit columns" button (`Columns3`) directly in `LabToolbar`.
   - Updated header button in `AppHeader.tsx` to `aria-label="Auto-fit columns"` and `title="Auto-fit columns"`.
