# MIC-306: Gantry: add an 'Auto-fit columns' button in the top-right header that re-balances all open vertical panels

- Project: Gantry
- Status: done
- Priority: medium
- Agent: Pegasus

- Updated: 2026-11-18

## Request

Acceptance checklist:
1. Add a button at the top right of the Gantry header (next to the existing describe-panel toggle, see the attached screenshot) that auto-fits the vertical panels (columns).
2. The button detects every panel currently open (for example the requirement form, the AI validation chat, the right PBI/Documents panel, and the markdown file panel that opens next to a document) and sets sensible widths automatically, so the user no longer drags each divider by hand.
3. If the left sidebar is collapsed or expanded and the user presses the button again, the panels are re-fitted to use the available width.
4. Works in dark and light mode and matches the bigMike Lab button style.

What to do: find the resizable panel layout in the Gantry frontend (requirement screen with three columns, document view with markdown panel, and the sidebar from MIC-294 and MIC-277). Implement a shared fit function. Suggested approach: measure the available width, give each open panel a width proportional to its content weight (for example form 30%, chat 30%, right panel 40%), respect each panel's minimum width (see MIC-301 and MIC-299 on min-width limits), and apply it with a short animation. Optionally keep the result until the user drags a divider again. The button must be hidden or disabled when only one panel is open. Add a tooltip 'Auto-fit panels'. Add a unit test for the width computation.

How to check: run npm run build and the tests. Open the requirement screen and a document with the markdown panel, press the button and take screenshots before and after. Collapse the left sidebar, press again and confirm the panels fill the space. Check minimum widths are never violated.

Keep: existing layout behavior, sidebar resizing, and Gantry stays separate from Gantry Enterprise. English-only UI. Commit and push when done. Related tasks: MIC-301, MIC-299, MIC-294, MIC-277, MIC-290.
