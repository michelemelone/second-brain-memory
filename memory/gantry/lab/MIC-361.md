### What I changed (repo `gantry/programs`, branch `main`)

| Area | Change |
|---|---|
| State model | `RequirementState.runs[]`: `{ number, start, end, status, changes? }` |
| Runs | New `requirements/runLog.ts`: numbering, the evidence of one run (only the phases completed in it), the Build log / Verification log blocks, the dated Change log block |

| Edit API | `PUT /api/backlog/:id` stays blocked (409) during a run; after it, changes to title, description, acceptance criteria or relation go to section 7 with the request verbatim and the previous text |
| Migration | `npm run requirements:migrate-runs` (dry-run by default, `--apply`, `--report`), idempotent |
| UI | “Start run” + “Last run: Run 1 · succeeded” + the run history in the toolbar; “Run N in progress, read only” while running; Backlog table and Start dialog follow |
| Docs | `Process.md` describes numbered runs and the Change-log rule |
