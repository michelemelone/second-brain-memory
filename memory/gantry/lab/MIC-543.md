- **Default Agent Choice:** Marked with a `Default` badge in the list. Under "More", "Make this the default model" sets scope default.
- **Composer Commands:** "Compact this chat" and "Clear this chat" are placed under "More" and disabled while busy.
- **Icon Trigger:** Supported via `variant="icon"` for table rows (e.g. Backlog Delivery Agent column).
