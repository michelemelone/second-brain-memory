- **What it reloads:** the `memory/bigmike` subtree and the memory status. It does not reload the whole Second Brain tree. A bigMike file that is open in a tab is re-read too.
- **States:**

  - **Success:** it shows "Last refreshed HH:MM:SS · N files (X wiki, Y chats)", so you can watch the memory grow.

- **Supporting changes:** `fetchTree` in `web/src/api.ts` now takes an optional path. The server already supported it. `App.tsx` and `styles.css` have small edits.
