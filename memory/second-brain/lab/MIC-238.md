# Report: Task MIC-238

## What was done
1. **Fixed Event Handling in ContextMenu ([web/src/ContextMenu.tsx](file:///home/beedme/data/workspace/second-brain-app/web/src/ContextMenu.tsx))**:
   - Prevented `.ctx-back` from swallowing click events prematurely on `.ctx-item`: added `onMouseDown={(e) => e.stopPropagation()}` on `.ctx-item`, and restricted backdrop dismissal on `.ctx-back` strictly to direct backdrop clicks (`e.target === e.currentTarget`).
   - Adjusted item click execution order so `it.onClick?.()` fires before `onClose()`, ensuring callbacks and state transitions occur reliably.
   - Refactored sub-menu rendering into a dedicated `SubMenu` component with stop-propagation handlers and screen-overflow detection (auto-flipping to the left if overflowing the viewport).
   - Stabilized Escape listener cleanup with `closeRef` to avoid unnecessary listener thrashing.

2. **Clean State Management in FileMenu ([web/src/FileMenu.tsx](file:///home/beedme/data/workspace/second-brain-app/web/src/FileMenu.tsx))**:
   - Resolved the issue where context menu actions or dismissals left the parent `fileTarget` in a dirty/orphaned state. Introduced a unified `closeAll()` routine that synchronizes `target`, `shown`, `ask`, and invokes parent `onClose()`.
   - Tracked dialog requests synchronously across React state batches using `askRef`, ensuring immediate dismissal when closing the menu without an active modal dialog while keeping dialogs open for confirmation.
   - Ensured actions without dialogs (e.g. `Make a copy`, `Bookmark`, `Copy path`, `Search in folder`) invoke `closeAll()` upon completion (or failure), preventing stuck file targets.
   - Preserved dialog state on write errors (e.g. top-level folder constraints or network failures) with descriptive error notices rather than unmounting with corrupted state.

3. **Top-Level Constraint Verification**:
   - Implemented `isTopLevel(node)` checking root (`""`) as well as single-segment paths (`node.path.split("/").length <= 1`).
   - Disabled `Rename...`, `Delete`, and `Move` options for top-level entries and root. Added validation guards in `rename`, `remove`, and `move` handlers to report clean notifications without triggering invalid requests.
   - Disabled `Make a copy` on the root workspace node.

4. **Dropdown Toggle in Toolbar ([web/src/App.tsx](file:///home/beedme/data/workspace/second-brain-app/web/src/App.tsx))**:
   - Added toggle behavior to the "Change sort order" button so clicking the button while `sortMenu` is open closes the menu cleanly instead of reopening it.

5. **Unit Tests & Verification**:
   - Added unit test suite in [web/tests/menu.test.ts](file:///home/beedme/data/workspace/second-brain-app/web/tests/menu.test.ts) testing `isTopLevel`, `copyName`, and menu item event invocation order.
   - Verified that all 114 tests pass (`npm test`).
   - Verified production build completes without issues (`npm run build`).
