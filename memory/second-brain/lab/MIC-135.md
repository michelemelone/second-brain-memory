**Suggestions (none blocks the merge)**

1. `MemoryRefresh.tsx:~20`: the refresh updates the counts and reloads the open files, but it does not call `reload()` on the explorer tree. A new file in `memory/bigmike` therefore stays missing from the sidebar until the user reloads the page. Fix: pass the `reload` function from `App.tsx` into `onRefreshed`.
2. `MemoryRefresh.tsx:~19`: the `getMemoryRepo()` result is thrown away. If bigMike is down, the whole refresh shows "failed" even though the file read worked. Either use the result or make the call optional.
3. `SettingsPanel.tsx:~35`: `refresh` depends on `dirty`. Editing a schedule recreates the 5-second polling timer. It still works, so this is cosmetic.
