**Done**
- **Left sidebar:** a Files / Search / Bookmarks tab strip, plus a Bookmarks button in the activity bar.
- **Files toolbar:**
  - New note and New folder.
  - A sort menu (A–Z, Z–A).
  - An auto-reveal toggle that opens the folders above the open note and scrolls to it.
  - An Expand all / Collapse all toggle.
- **File and folder right-click menu:**
  - Actions: New note, New folder, Make a copy, Move to..., Search in folder, Bookmark, Copy path (path, name, wiki link), Rename..., and Delete in red.
  - Each write is one git commit, and the small dialogs ask for the name or confirm the delete.
  - Make a copy copies notes and text files only. A folder copy skips other files and says how many.
- **Search:**
  - A box with an "Aa" match-case toggle and an options popup. Clicking an operator in the popup inserts it.
  - Operators: `path:`, `file:`, `tag:`, `line:()`, `section:()`, `[property]` and `[property:value]`.
  - They are handled on the server and tested.
  - The "Ask the model" button is kept.
- **Bookmarks:** New bookmark (the open note), New group, Collapse all, Expand all and Search. The empty state reads "No bookmarks found". They persist in the browser's localStorage and follow renames and deletes. The right-click menu removes a bookmark or moves it into a group.
- **Tabs:**
  - A right-click menu with Close, Close others, Close all, Pin / Unpin, Move to new window, Split right and Split down.
  - Pinned tabs sort first and have no X.
  - Move to new window opens the note in a new browser tab.
  - Splits show a second pane with its own close button.
- **Right sidebar:**
  - Icon tabs: Backlinks (Linked mentions and Unlinked mentions, each with a count), Outgoing links, Tags, Outline and AI chat.
  - A toolbar with Collapse all, Expand all, a sort toggle and a filter box.
  - Clicking a tag searches `tag:<name>`.
- **AI chat:** conversations kept in the browser, with a history list, new chat and delete. Each chat has an agent selector filled from the engines list, and answers come from a local search of your memory followed by the model. See "Please check" below.
- **Mobile:** the right sidebar is a slide-in drawer, and it starts closed under 720px width.
