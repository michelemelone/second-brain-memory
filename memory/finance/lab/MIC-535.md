# MIC-535: Finance: responsive layout for foldable/mobile, touch & pointer column resizing, resizable AI drawer, and adaptive header

- Project: Finance app
- Status: done
- Priority: high
- Agent: Libra

- Updated: 2026-11-27

## Request

1. Pointer and touch events for left sidebar: In web/components/app-shell.tsx, replace onMouseDown with onPointerDown and setPointerCapture for handleResizeStart. Resizing must work smoothly with finger touch on mobile and foldable screens (Galaxy Z Fold 7 folded ~380px and unfolded ~880px) as well as mouse on desktop. Verified by dragging the handle with pointer/touch events.
2. Resizable right AI drawer: In web/components/ai-drawer.tsx, add a draggable divider on the left edge of the desktop/docked drawer with pointer and touch events (setPointerCapture). Allow resizing the AI drawer width dynamically within constraints (min 260px, max 500px, default 340px) and persist the width in localStorage under 'finance:ai-drawer-width'. On drag, smoothly adjust --ai-w and padding without layout lag.
3. Responsive and overflow-proof header: In web/components/app-shell.tsx, ensure the header controls never overflow off-screen or get obscured behind the AI drawer. Make the search bar flexible/collapsible (max-w-[180px] or collapsible on small viewports) so that the Auto-fit button (Columns3), AIDrawerToggle, Theme button, and Sign out button remain visible, unobstructed, and clickable across all viewports (from 360px up to 1400px+).
4. Adaptive auto-fit and viewport budget: Clicking the Columns3 button must intelligently balance the columns based on the window's actual viewport width. On viewport widths below 1000px (such as Galaxy Z Fold unfolded ~880px), if the AI Drawer is open, Columns3 must ensure the central dashboard area maintains at least 450px of breathing room (collapsing the left sidebar to icon mode 64px if necessary, and sizing the AI drawer to its compact width).
5. Double-click reset on dividers: Double-clicking the left sidebar divider resets its width to 190px (and expands if collapsed); double-clicking the AI drawer divider resets its width to 340px.
6. Clean build and service restart: Run npm run build in personal-finance/web exiting 0 without TypeScript or lint errors. Queue service restart with bigmike-restart "Finance app".

### Context & Reproduction
- On Galaxy Z Fold 7 unfolded (~880px), Ledger dashboard is severely compressed because md: breakpoint triggers desktop docking: left sidebar (190px) + right AI drawer (384px fixed) leaves only ~306px for the center content.
- In addition, the header search bar (w-64) causes horizontal overflow that pushes the Auto-fit Columns3 button, theme toggle, and drawer toggle off-screen behind the fixed AI drawer.
- The left divider only listens to onMouseDown, preventing touch dragging on mobile/foldable screens, and the AI drawer has no resizing divider at all.
