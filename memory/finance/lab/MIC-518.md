# MIC-518: Finance: Right sidebar panel with embedded bigMike

**Status:** Done | **Updated:** 2026-11-27 | **Repo commit:** 0ae869a

## Summary

Implemented a responsive right sidebar panel (desktop) and drawer (mobile) with an embedded bigMike instance scoped to the personal-finance project. Users can now ask bigMike questions directly from the Finance app without leaving the interface.

## Implementation Details

### New Files Created
- `web/components/ai-drawer.tsx` - AIDrawer component (responsive sidebar + mobile drawer) and AIDrawerToggle button

### Modified Files
- `web/components/app-shell.tsx` - Added AIDrawer integration, toggle button in header, localStorage state persistence

### Key Features
1. **Toggle Button** - MessageSquare icon in the header (right side, before logout/theme buttons)
2. **Desktop Sidebar** - 380-420px wide panel on the right (hidden on mobile, shown on md+ breakpoints)
3. **Mobile Drawer** - Full-width drawer from the right with backdrop (shown on mobile, hidden on md+)
4. **Smooth Transitions** - CSS transitions for open/close animations (300ms duration)
5. **State Persistence** - localStorage key `finance:ai-drawer-open` saves panel state between navigation
6. **Dynamic Origin Detection** - Automatically detects bigMike URL:
   - Public: `https://bigmike.beedme.online` (if on .beedme.online domain)
   - Local: `http://bigmike.local` (if on .local domain)
   - Dev: `http://localhost:3738` (or custom hostname:3738)
7. **iframe Embedding** - Uses bigMike embed parameters: `?embed=personal-finance&chromeless`
8. **Permissions** - iframe allow attribute: `microphone; clipboard-write; clipboard-read`
9. **Keyboard Navigation** - Escape key closes the panel
10. **Mobile UX** - Click backdrop to close, automatic close on route change (mobile only)
